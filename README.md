## 📌 Introdução

Aplicativo de vizualização de diferentes telas com navegação entre elas
---

## 🛠️ Funcionalidades

• Cadastro

• Login  

• Autenticação de login

• Armazenamento de dados via Async Storage

• Navegação entre as telas por meio do Drawer

• Opção de Logout

• Opção de Apagar conta 

---
## 🧰 Pré Requisítos

• Node.js 

• IDE ( Exemplo: VS Code)

• Expo Go (App Mobile que permite vizualização do projeto no celular) 

• NPM

• GIT 

---

## ⚙️ Como instalar e executar

1. Clone o repositório:

```bash
https://github.com/MarinhoCorrea/NavegacaoReactNative
```

2. Acesse a pasta do repositório:
   
```bash
cd NavegacaoReactNative
```
3. Instale os arquivos necessários para a executar o projeto:
   
```bash
npm i
```

4. Execute o programa principal:

```bash
npx expo start --tunnel
```
